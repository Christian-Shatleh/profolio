# Profolio interactive experience

This is a self-contained HTML/CSS/JavaScript website with one bundled image asset.

## Files

- `index.html` — Complete responsive experience, styling, scripted animations, and audio generated using the browser Web Audio API.
- `ramiz-gallery.png` — Image collage used by the photo/X scene.

## Run locally

Open `index.html` in a modern browser. No installation, account, API key, database, or build step is required.

## Publish on GitHub Pages

1. Create a repository and upload both files to its root.
2. In repository **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
3. Open the provided GitHub Pages URL.

Browser security restrictions prevent sound from automatically playing just by opening a link; visitors must tap **START** to enable audio. This website does not access device files or accounts.

## Permissions

You can view, edit, copy, and host the supplied source files. A ZIP cannot transfer GitHub, phone, account, hosting, or other platform permissions. Make sure you have the person's permission before publicly sharing their photos.
